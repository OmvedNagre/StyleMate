# StyleMate Android APK

`StyleMate-0.1.0.apk` is the local sideload build for ARM Android devices running Android 7.0 or newer. It uses the generated project's debug signing key. The app includes its JavaScript bundle and runs independently of Expo Go and Metro.

Photo capture, gallery selection, and manual clothing tags are available. Image recognition is paused. The APK is stored locally in this folder and excluded from Git.
